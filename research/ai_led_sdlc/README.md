
# AI-Led SDLC Markdown Package

This zip contains a consultant-style markdown deliverable set for the AI-led SDLC landscape study.

## Files

- `01_main_report.md` — long-form landscape report
- `02_methodology_and_rubric.md` — study design and normalization logic
- `03_source_corpus.md` — primary source list with URLs
- `04_comparison_matrix.md` — cross-method comparison tables
- `05_enterprise_reference_model.md` — compact operating model summary
- `profiles/` — short per-framework profile sheets

## Suggested reading order

1. `01_main_report.md`
2. `04_comparison_matrix.md`
3. `05_enterprise_reference_model.md`
4. `profiles/` for workshop or leadership discussion support
5. `03_source_corpus.md` for source validation

## Notes

- Citations in the markdown use the form `[S#]`.  
- The corresponding source details and URLs are in `03_source_corpus.md`.
- This package emphasizes **process structure**, not product feature comparison alone.
