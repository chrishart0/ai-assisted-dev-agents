
# Spec Kit Profile

## What it is
Spec Kit is an open-source toolkit for spec-driven development with coding agents. It is designed to turn specifications into executable artifacts that guide implementation instead of becoming stale documents. [S8]

## Workflow shape
The canonical chain is:
1. constitution;
2. specify;
3. plan;
4. tasks;
5. implement. [S8]

## Distinctive artifacts
- constitution
- specification
- implementation plan
- tasks
- implementation workflow artifacts [S8]

## How AI participates
The user steers, while the coding agent generates and refines the artifacts and then implements from them. The method is strongly oriented toward making the spec the source of truth rather than letting code generation become the primary reasoning step. [S8]

## How humans stay in control
Humans validate each phase before advancing. The process is explicit that each phase has a job and should be validated before moving forward. [S8]

## Why it matters
Spec Kit is one of the strongest public examples of **executable intent**. It directly addresses the “looks right but is wrong” problem by formalizing the artifact chain that precedes agentic implementation. [S8]

## Best fit
Teams that need better upfront artifact discipline and want a reusable, open-source process for spec-first AI-assisted delivery.
