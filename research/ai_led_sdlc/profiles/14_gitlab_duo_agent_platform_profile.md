
# GitLab Duo Agent Platform Profile

## What it is
GitLab Duo Agent Platform is an AI orchestration layer for the software lifecycle, centered on agents and flows that can work asynchronously across issues, merge requests, CI/CD, security, analytics, and other DevSecOps surfaces. [S10]

## Workflow shape
GitLab describes four main interaction modes:
1. agentic chat;
2. custom flows triggered in issues or MRs;
3. foundational flows such as Developer, Code Review, Fix CI/CD Pipeline, Convert to GitLab CI/CD, and Software Development Flow;
4. external agents triggered inside GitLab workflows. [S10]

## Distinctive artifacts and controls
- merge requests
- flow definitions
- pipeline outputs
- AI catalog entries
- flow sessions and execution logs
- policy-driven agent and model controls [S10]

## How AI participates
GitLab emphasizes multi-agent flows that run asynchronously in the background and handle end-to-end tasks from analysis to implementation. The platform is especially strong on CI/CD remediation, MR automation, and event-driven orchestration. [S10]

## How humans stay in control
GitLab frames flows as governed under organizational rules and identity, with repeatable execution, administrative controls, and traceability of sessions. [S10]

## Why it matters
GitLab is one of the clearest examples of **event-driven, many-to-many AI orchestration** in DevSecOps. It broadens the conversation beyond coding agents to include flows that automate work across planning, merge, pipeline, and security boundaries. [S10]

## Best fit
Organizations that want AI-led workflows to operate across the broader DevSecOps system, not only inside the IDE or PR review loop.
